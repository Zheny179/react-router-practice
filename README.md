# React Router — Практическая работа

Учебный проект для отработки навыков клиентской маршрутизации в React с
использованием **React Router**. Проект демонстрирует работу с
декларативной и программной навигацией, динамическими маршрутами,
query-параметрами и состоянием при переходах.

---

## 📋 Реализованные возможности

- **Декларативная навигация** — `<Link>` и `<NavLink>` с активной подсветкой
- **Query-строки** — чтение и обработка query-параметров через `useSearchParams`
- **Передача state** — передача данных между маршрутами через `location.state`
- **Программная навигация** — редиректы через `useNavigate`
- **Редиректы** — автоматический переход с несуществующих страниц
- **Общий Layout** — единый `Header` и `Footer` на всех страницах через
  `<Outlet />`

---

## 🏗 Структура проекта

```
src/
├── components/
│   ├── Header.jsx            # Навигационное меню (NavLink)
│   ├── Footer.jsx            # Футер страницы
│   └── Layout.jsx            # Обёртка
├── pages/
│   ├── HomePage.jsx          # Главная
│   ├── AboutPage.jsx         # Статическая страница «О нас»
│   ├── SearchPage.jsx        # Поиск через query string (?q=...)
│   ├── LoginPage.jsx         # Логин: Link + программная навигация
│   └── NotFoundPage.jsx      # Страница 404 с редиректом
├── App.jsx                   # Конфигурация маршрутов (<Routes>)
├── main.jsx                  # Точка входа
└── index.css                 # Глобальные стили
```

## 🚀 Установка и запуск


1. Склонируйте репозиторий:
    ```bash
    git clone https://github.com/Zheny179/currency-exchange-calculator.git
    cd currency-exchange-calculator
    ```
2. Установите зависимости:

    ```bash
    pnpm install
    ```

3. Запустите сервер разработки:

    ```bash
    pnpm dev
    ```


## 📝 Описание заданий

| # | Задание                                       | Решение                                                                |
|---|-----------------------------------------------|------------------------------------------------------------------------|
| 1 | Настроить структуру проекта и router          | Созданы компоненты и страницы, маршруты описаны в `App.jsx`            |
| 2 | Навигационные ссылки на всех страницах        | `Header.jsx` с `NavLink` размещён внутри `Layout.jsx` через `<Outlet>` |
| 3 | Query string на странице поиска               | `useSearchParams()` для чтения `?q=` и фильтрации                      |
| 4 | Кнопка «Log in» с передачей state             | `<Link to="/" state={{ login: "You are logged in" }}>`                 |
| 5 | Кнопка «Forgot login» — программная навигация | `navigate("/", { state: { login: "You are not logged in" } })`         |
| 6 | Отображение `state.login` на главной          | `useLocation().state?.login` внутри `<p>`                              |
| 7 | Редирект с 404 на главную                     | `<Navigate to="/" replace />` в `NotFoundPage` или через `*` маршрут   |

## 📌 Ключевые концепции React Router, использованные в проекте

- **`createBrowserRouter`** — современный API конфигурации маршрутов (Data
  Router)
- **`<Outlet />`** — рендер вложенных маршрутов внутри layout-компонента
- **`useSearchParams`** — работа с query-параметрами (`?q=value`)
- **`useNavigate`** — программная навигация (push/replace)
- **`useLocation`** — доступ к текущему URL и переданному `state`
- **`<Navigate>`** — декларативный редирект
